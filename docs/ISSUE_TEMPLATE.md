# Como relatar um problema / How to report a problem

Copie o modelo abaixo numa mensagem (WhatsApp, e-mail ou uma *Issue* no GitHub) ou cole
direto no Claude/Codex. Quanto mais exato, mais rápido a correção.
*(Copy the template below into a message, a GitHub issue, or straight into the AI.)*

```
O que aconteceu (what happened):
  Ex.: "Ao fechar a comanda da mesa 4 apareceu 'Erro 500' e o total não salvou."

O que eu esperava (what I expected):

Onde (where): link ou nome da tela, e em qual aparelho (celular/computador, navegador)

Quando (when): data e hora aproximada. Aconteceu uma vez ou sempre?

Passo a passo para repetir (steps to repeat):
  1.
  2.
  3.

Quem foi afetado (who is affected): só eu / alguns clientes / todo mundo

Urgência (urgency):
  [ ] Parou tudo — ninguém consegue trabalhar
  [ ] Atrapalha, mas dá para contornar
  [ ] Pode esperar / sugestão de melhoria

Anexos (attachments): print da tela ou vídeo curto.
  NÃO envie senhas, nem dados pessoais de clientes (CPF, telefone) nos anexos.
```
